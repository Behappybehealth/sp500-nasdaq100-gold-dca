#
# 为什么这里不钉 `==`：Cloud 的 Python 版本由平台选定、通常低于本机的 3.14，
# 钉成本机实装版本可能找不到对应 wheel 直接部署失败。所以本文件只给"范围 + 上界"，
# 复现开发机用另一份 requirements-dev.lock（全钉，见 BUG-015 确认记录）。
#
# 上界的作用：拦住上游大版本改动把线上打挂（pandas 2→3 就有不兼容改动）。
# streamlit 的下界钉在 1.61.1：UI 全部用 1.46+ 才有的 width="stretch" 布局参数，
# 低于此版本直接 TypeError 起不来；同时它也是开发机实装实测版本。其余依赖的下界
# 是历史声明、并未实测——真正验证过的组合看 requirements-dev.lock。
