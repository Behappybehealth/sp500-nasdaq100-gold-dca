# 标普500 / 纳指100 / 黄金动态定投核心策略

> 【活文档 · 更新时机：策略调整同期】索引见 [docs/README.md](../docs/README.md)。
> **本文件是策略说明的唯一事实源**——应用 Tab6「策略说明」页面直接渲染本文件。
> 本策略用于教育与决策辅助，不承诺收益，也不替代持牌投资顾问意见。市场有风险，最终交易由用户确认。

## 这是什么

一套**标普500 / 纳指100 / 黄金（XAUT）三资产动态定投系统**：本地 Python 决策引擎 + 网页决策台 + Claude Skill 两个使用入口。
它不预测市场涨跌，而是每天用最新行情计算"今天这笔钱的性价比"，回答三个问题：**今天买不买、买多少、怎么分**。

**能帮你做什么：**

- **每日决策**：给出建议总金额、三资产金额与比例、保守/平衡/进取三档执行方案
- **仓位管理**：自动汇总持仓、估值、浮盈浮亏、年化 XIRR（按每笔资金实际进出日期计算）
- **预算纪律**：每月预算按交易日摊平，防止"月初冲动、月末干瞪眼"
- **风险保护**：高位过热自动减码、趋势破坏时拒绝接飞刀、黄金在权益走弱时自动升权
- **完整记账**：成交/跳过都有记录，每天先复盘上期结果再出新建议

## 1. 核心目标

以人民币月度预算 30000 元为上限，在标普500、纳指100、黄金三个资产之间做 3~6 个月及更长期的动态定投。策略不做机械日投，而是每天先复盘上一条记录与累计持仓，再结合最新行情、历史趋势、回撤、波动和分散信号，判断今天是否买、买多少、如何分配。

风险画像：不能接受本金实际亏损（卖出实现的亏损），但可接受较大浮亏与更长持有周期。本策略无法保证不亏损，只能通过分批买入、分散配置与动态调仓降低永久亏损的概率。

## 2. 默认资金节奏

- 月度预算：30000 RMB。
- 默认每个交易日都投：每日基准 ≈ 30000 ÷ 当月交易日数（20 个交易日 ≈ 1500）。
- 本月可用池 = 30000 − 本月已投 − 作废份额（作废份额 = 30000 × 启动前已过去交易日 ÷ 当月交易日）；月中启动不追补启动前份额。
- 跳过（策略不买或用户放弃）的金额不作废，自动摊入后续交易日（可用池 ÷ 剩余交易日逐日重算）。
- 单次金额 = 每日基准 × 部署系数（0~1.8，随权益评分每日变化）；累计不超过可用池，除非用户明确确认。
- 月末释放：自然月剩余天数 ≤ 7 天且可用池 > 0 时，单次下限提高到当日基准，可用池尽量月底前投完，除非用户明确放弃。

## 3. 标的与中性权重

| 资产 | 默认 proxy | 中性权重 | 常规区间 | 定位 |
|---|---:|---:|---:|---|
| 标普500 | SPY / ^GSPC | 35% | 20%~55% | 核心权益仓位 |
| 纳指100 | QQQ / ^NDX | 45% | 30%~70% | 成长弹性仓位 |
| 黄金 | XAUT / GC=F | 20% | 10%~30% | 防御、抗通胀、分散 |

默认不加入其他资产到每日买入分配；可作为观察项提示债券、货币基金、A/H 股宽基等。

## 4. 每日固定流程

```
复盘上一条记录 → 增量更新行情（本地缓存，只抓新增）→ 算本月可用池
→ 连续评分（每资产）→ 定金额（部署系数）→ 定比例（评分倾斜）
→ 输出建议 → 你实盘执行 → 回报成交 → 复述确认后才记账 → 次日再循环
```

1. 读取记录：云端模式从 Google Sheets 同步该用户的记录到 `data/users/<用户名>/`；单机模式读 `data/` 根目录的 CSV。
2. 在今日建议前，先展示上一条记录 / 前一日结果。
3. 抓取最新行情与历史数据，尽量覆盖 10 年日线；历史行情本地缓存在 `data/market_history/*.csv`，每日只做增量更新。
4. 计算累计持仓、当前估值、未实现盈亏、收益率和年化 XIRR（按每笔现金流实际日期求解）。
5. 输出一张完整宽表，包含组合汇总、三类资产、现金/待投。
6. 根据多因子模型给出今日行动、金额和比例。
7. 提供保守 / 平衡 / 进取三档方案。
8. 等待用户回复实际买入或跳过结果，确认后追加记录。

## 5. 多因子评分框架

每日对每个资产计算以下信号：

- 趋势：相对 20 / 60 / 120 / 252 日均线的位置。
- 回撤：相对 252 日高点的回撤幅度。
- 动量：1 / 5 / 20 / 60 / 120 / 252 日收益率。
- 波动：20 / 60 日年化波动率。
- 分散：资产之间近期相关性与风险集中度。
- 位置：价格在 252 日高低点区间中的分位。

### 权益资产加减规则

- 低于 60 / 120 日均线但长期趋势仍可接受：提高买入吸引力。
- 接近 252 日高点且短期上涨过快：降低当日投入或跳过。
- 长期趋势向上、短期回撤：适合分批加仓。
- 长短期趋势同时转弱且波动升高：降低权益比例，增加黄金或现金。

### 黄金加减规则

- 权益资产相关性升高、波动上升或回撤扩大：提高黄金权重。
- 黄金短期过热、远离均线：降低追高比例。
- 黄金常规保持 10%~30% 区间，极端环境需临时突破上限时必须经用户确认。

### 评分公式（每日连续计算）

每个资产：`score = 0.50×回撤价值 + 0.25×趋势 + 0.15×动量 − 0.45×过热 − 0.20×过热² − 0.15×波动`

- 回撤价值 = clip((回撤深度 − 4%) ÷ 12%, ±1) × 趋势健康门控 clip((趋势+1.2)/1.4, 0~1)——趋势破坏时回撤是飞刀不是机会
- 趋势 = clip(60/252 日均线偏离的均值 ÷ 12%, ±1)，封顶 +0.4（只防御不追高）
- 动量 = clip(60/120 日收益的均值 ÷ 20%, ±1)，封顶 +0.5（防止助推追高）
- 过热 = RSI14、252 日区间位置、20 日涨幅合成（0~1），二次项确保极端行情能压到不买
- 波动 = 20 日年化波动率超过 18% 的部分（0~1）

## 6. 今日金额与比例（连续模型，一体化）

不做“几个过热就跳过”这类离散计数分级。每天由最新行情直接计算：

- 今日金额 = 基准 × 部署系数
  - 基准 = 可用池 ÷ 剩余交易日（默认每天投）；可用池 = 30000 − 本月已投 − 启动前作废份额；用户输入 A 时以 A 为基准
  - 部署系数 = `clip(1 + 1.1 × 权益综合评分, 0, 1.8)`；< 0.15 时今日不买，仅记录观察，金额摊入后续交易日
- 今日比例 = `中性权重 × (1 + 0.9 × 资产评分)`；黄金在权益趋势走弱时获防御加成（+0.6×|权益趋势均值|），截断到权重区间后归一化
- 月末释放：剩余 ≤ 7 天且建议金额 > 0 时，下限抬到「剩余预算 ÷ 剩余机会」；不推翻“不买”决策

沟通时按部署系数描述力度：

| 部署系数 | 沟通用语 |
|---:|---|
| ≥ 1.35 | 积极买入 |
| 1.05~1.35 | 建议买入 |
| 0.75~1.05 | 正常推进 |
| 0.40~0.75 | 谨慎少量 |
| 0.15~0.40 | 小额试探 |
| < 0.15 | 今日不买，延后观察 |

## 7. 三档执行模板

以模型建议金额 S 为锚：

### 保守方案

- 总金额：0.5S~0.8S。
- 权益较低，黄金/现金较高。
- 适合高位、波动偏高或用户希望降低回撤。

### 平衡方案（默认推荐）

- 总金额：S（模型输出）。
- 按模型信号倾斜后的权重分配。
- 适合绝大多数正常定投日。

### 进取方案

- 总金额：1.2S~1.4S，不超自然月剩余预算。
- 提高标普500和纳指100权重，黄金保留分散功能。
- 只适合用户能承受更大短期波动，且月度预算仍充足。

## 8. 回测结论（2021-08 ~ 2026-08，1254 条任意起点路径，诚实版）

- 坚持定投超 3 个月的路径全部正收益（注意：终点在高位，有窗口效应）
- 最痛路径：-28.4% 回撤、连续 248 个交易日浮亏，最终 +67.6%
- 动态机制 vs 固定金额：牛市里代价约 0.3~0.9pp XIRR（"保费"），冲顶回落行情里明显胜出（黄金 +3.7pp）——**它是尾部保险，不是收益增强器**
- 任何单品种回撤都远深于三资产组合：分散本身就是最大的风控

## 9. 宽表输出字段

每日输出必须尽量合并为一张宽表：

| 层级 | 日期 | 期数 | 资产 | 上一条记录类型 | 上一条投入金额RMB | 累计投入RMB | 持仓份额 | 最新价格 | 当前估值RMB | 未实现盈亏RMB | 收益率 | 年化XIRR | 组合权重 | 今日建议金额RMB | 今日建议比例 | 备注 |
|---|---|---:|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|

没有历史记录时，组合汇总、标普500、纳指100、黄金、现金/待投也要输出，金额和份额填 0 或“暂无”。

## 10. 记录规范

存储位置：云端模式写 Google Sheets 的对应工作表（每用户本地缓存同步到 `data/users/<用户名>/`）；单机模式写 `data/` 根目录 CSV。字段口径两种模式一致。

### 交易记录

字段：`date,action,asset,symbol,currency,amount_rmb,price,shares,fee_rmb,fx_rate,notes`

- 每个资产一行。
- `action` 使用 `buy` / `sell` / `adjust`。
- 若只提供金额和价格，自动计算份额。
- 若只提供金额和份额，自动计算价格。
- 写入前先复述确认；确认后追加，不覆盖。

### 观察记录

字段：`date,action,total_suggested_rmb,user_amount_rmb,decision_level,sp500_weight,ndx100_weight,gold_weight,reason,notes`

- 用于记录跳过买入、仅观察或只生成建议。

## 11. 纪律与边界

- **建议 ≠ 成交**：系统从不自动记账，只有你确认复述内容后才追加写入（只追加、不覆盖）
- **无法保证不亏**：策略接受浮亏换长期收益，只能通过分散和调仓降低永久亏损概率
- **不碰杠杆**：默认不建议使用杠杆。只有用户明确要求评估杠杆时，才讨论小比例、严格止损和最大亏损承受能力；杠杆不作为长期定投默认策略
- **不擅自加新标的**；黄金估值用 XAUT-USD ± 1% 偏差，实际盈亏以你报的欧易成交净值为准

## 12. 数据与隐私

行情来自 Yahoo Finance / 东方财富公开接口。**你的成交记录、观察记录和预算设置存放在 Google Sheets 云端表格**（项目专用 Google 服务账号下的私有表，只有表格所有者和被授权的应用能读写）；应用服务器上留有给你本人生成的本地缓存（`data/users/<用户名>/`），用于每次计算提速。行情缓存（不含任何个人信息）保存在应用项目目录并随代码仓库分发。登录 PIN 以 PBKDF2 加盐哈希存储，明文不落盘。
